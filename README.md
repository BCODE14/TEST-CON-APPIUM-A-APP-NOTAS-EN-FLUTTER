# TEST-CON-APPIUM-A-APP-NOTAS-EN-FLUTTER
Desarrollé una prueba funcional automatizada con Appium sobre una aplicación de notas construida en Flutter.
El objetivo de la prueba fue validar el correcto funcionamiento de las principales características de la aplicación, como la creación, edición y eliminación de notas.

La automatización permite verificar de manera rápida y confiable el comportamiento de la app en distintos escenarios, reduciendo el tiempo de prueba manual y asegurando una mayor calidad en cada iteración de desarrollo.
